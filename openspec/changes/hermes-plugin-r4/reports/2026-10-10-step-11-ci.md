The repository has no remote yet, so the steps of `.github/workflows/tests.yml` cannot run in GitHub
Actions. They were run locally, in the order the workflow lists them, with the interpreter the workflow
installs (Python 3.11) on Windows; the Linux leg is reported as not run.

Workflow as it stands (`.github/workflows/tests.yml`, unchanged this round):

```yaml
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest]
        python-version: ["3.11"]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
      - name: Install pytest
        run: python -m pip install --upgrade pip pytest
      - name: Run the suite
        run: python -m pytest -q
```
