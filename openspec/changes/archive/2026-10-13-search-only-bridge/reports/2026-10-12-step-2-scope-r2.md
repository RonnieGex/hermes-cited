## What was wrong

- **B01.** With the real `agent.secret_scope` pinned, multiplexing active and `set_secret_scope(None)`,
  `register` fell through `_register_without_scope` and registered the **full** surface over the root
  environment, so a handler prepared a call to `/api/mcp` with the root `CITED_MCP_TOKEN`. A
  `ModuleNotFoundError` raised by a dependency inside `agent` was read as "host absent" and fell back to
  `os.environ`. `active_scope` accepted any non-null value, not a `Mapping`, and accepted a blank home.
  `settings_for` read the environment for any registration without a home.
- **m01.** `_check_registration` compared homes as text, so the same directory written as
  `home/child/..` was rejected.
- **M02.** `tools.search_only` formatted `type(error).__name__: error` into the model-visible sentence, and
  the search transport branches of `client.py` interpolated the timeout, `URLError`, `OSError` and read
  failure texts.

## What was changed

`hermes_cited/config.py`:

- `_agent_is_absent(error)` is true only when the missing module name is `agent` (or a submodule of it);
  `host_is_present()` reports a present host that fails to import, so a broken dependency fails closed.
- `active_scope()` requires a `collections.abc.Mapping` and a non-empty home, and raises the redacted
  sentence otherwise.
- `canonical_home()` normalizes a home with `realpath` + `normcase` + `normpath`; `_check_registration`
  compares canonical identities, so `home/child/..` is the same profile and two genuinely different homes
  stay different.
- `settings_for` with an empty home fails closed while the host is present; only a run where `agent` is
  genuinely absent reads `os.environ`.

`hermes_cited/plugin.py`:

- `register` refuses registration (both modes) when the scope cannot be read; `_register_without_scope` is
  removed, so there is no environment fallback while Hermes is present.
- the search mode refuses a blank home before `cited_search` is registered and captures the canonical home.

`hermes_cited/client.py` and `hermes_cited/tools.py`:

- the search timeout, `URLError`, `OSError` and read-failure branches are fixed sentences; an exception
  outside those categories becomes the fixed sentence `Cited could not be called: the search transport
  failed before an answer was read.` No exception text, type name or transport metadata reaches the model.
