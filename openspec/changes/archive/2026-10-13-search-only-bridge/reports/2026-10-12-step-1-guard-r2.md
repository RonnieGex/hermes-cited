# Step 1.1 (round 2) — the isolation guard enforces overrides before any effect

- Change: `search-only-bridge` · Branch: `feature/search-only-bridge` · Agent: DeepSeek
- Date: 2026-10-12 · Python: `.venv\Scripts\python` (3.11.15) · `PYTHONDONTWRITEBYTECODE=1`
- Round 1 review item: **M03** (BROKEN, Major) — `guard_environment({})` succeeded and the autouse
  fixture did not enforce required overrides or paths.

## What was wrong

- `guard_environment` validated only the overrides that happened to be present: an empty mapping returned
  normally, so a run without a temporary home or a test origin was declared safe.
- `search_guard` registered `tempfile.gettempdir()` globally, so any path under the whole temp directory
  looked "registered" and the workspace check lost most of its force.
- `tests/conftest.py` installed only the socket guard; nothing connected the override/path prechecks to a
  test before its effects, and the ambient `HERMES_HOME` of the shell pointed at the personal installation
  `%LOCALAPPDATA%\hermes` without any test noticing.

## GREEN — the guard fails closed and the suite runs isolated

`tests/search_guard.py`:

- `guard_environment(env)` now requires `HERMES_HOME` and `CITED_URL`, guards the home against the
  registered temporary workspaces and rejects a forbidden origin, *before* returning; it returns the
  guarded home.
- the blanket `register_workspace(tempfile.gettempdir())` is removed.

`tests/conftest.py`:

- the autouse fixture registers this test's `tmp_path`, and when the inherited `HERMES_HOME` is outside a
  registered workspace (for example the personal installation) it replaces it with this test's own
  temporary home **before** the test body runs.
- a new autouse fixture removes the host modules one integration test added (`agent`, `hermes_cli`,
  `hermes_plugins`, `hermes_constants`, `gateway`), so a real-host test cannot make the legacy unit tests
  look like a run inside Hermes.

`tests/bridge_support.py`: `bound_scope` guards the profile home before the scope is bound, so every
bridge integration test refuses a foreign home before registration or a call.
